# Lista de Tarefas

Aplicação de lista de tarefas feita com Vue 3 e Vite.

## Funcionalidades

- Cadastro, conclusão, reabertura e remoção de tarefas
- Contador de tarefas pendentes atualizado automaticamente
- Busca por título (sem diferenciar maiúsculas de minúsculas)
- Filtro por situação (todas, pendentes, concluídas)
- Busca e filtro combinados
- Botão para limpar os filtros aplicados

## Rodando o projeto

```bash
npm install
npm run dev
```
